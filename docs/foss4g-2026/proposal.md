## タイトル

国土数値情報 道路データで作る、全国対応の到達圏・経路探索 Web アプリ

（2026-09-28 決定。「全国対応」は前回の事例紹介との違いと、概要の中心の「全国規模で速く動かす工夫」を示すため）

## 概要

経路探索や到達圏分析に使う道路ネットワークデータは、これまで有償のものが一般的でした。2026 年 4 月、国土交通省が国土数値情報の道路データ（全国約 2,400 万本）を CC BY 4.0 で公開し、商用でも自由に使えるようになりました。発表者はこれまでに、このライン形式のデータをノード・リンク形式の道路ネットワークに変換する手法を作り、到達圏分析・公共交通空白地域の抽出・津波避難シミュレーションなどに応用してきました（MIERUNE JCT #03「国土数値情報 道路データがひらく空間分析」・2026 年 6 月）。

その次の段階として、幅員 5.5m 以上の 388 万リンクに絞った全国の道路網を使い、地図上のどこをタップしても「車で何分で行けるか」を道路 1 本ごとに色分けして表示する Web API とアプリを作りました。経路探索もできます。

本発表では、全国規模で速く動かすための工夫を実測値とともに紹介します。

- **探索エンジンの選定**：同じ道路網で pgRouting と SciPy（メモリ上のグラフ）を比べ、結果は完全に一致したまま 10〜27 倍速くなりました。差はアルゴリズムではなく「グラフをどこに置くか」から生まれます。
- **描画**：道路は PMTiles のベクタタイルで配信し、MapLibre GL JS の feature-state で到達時間ごとに塗り分けます。塗る本数が数十万になると描画が詰まるため、画面に読み込まれたタイルの道路だけを太い道から少しずつ塗り、スマホでも約 1 秒で最初の色が出るようにしました。
- **公開**：データベースを使わない構成にし、Cloudflare Workers と Containers（0.5 vCPU・4 GiB）の上に載せました。前処理で道路網をそのまま読めるファイルにして起動を 44 秒から 10 秒に縮め、結果をバイナリで返して転送量を約 4 分の 1 にしました。

会場では公開版をデモします。

使った主なソフトウェア：MapLibre GL JS、PMTiles、SvelteKit、FastAPI、SciPy、GeoParquet、PostGIS / pgRouting（比較用）
